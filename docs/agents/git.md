# Git：中文提交并推送

每次落地的改动都要写成详细中文 commit，并立刻推到当前分支的远程。本地领先、远程看不见，不算完成。

## 提交

1. 把本次改动收成一次 commit；若含互不相关的几件事，按逻辑切成几次，每次都推。
2. 用 `git commit` 的 heredoc 写信息，语言为中文。
3. **标题**：一行，说清做了什么（模块或行为 + 结果）。
4. **正文**：写清改了什么、为什么、怎么验证。至少覆盖：
   - 行为变化（接口、数据、页面、规则）
   - 关键文件或模块
   - 取舍（刻意没做的、留给后续工单的）
   - 验证（命令与结果，例如 `pytest -q` 22 passed）

标题不够详细、没有正文、或只用英文，视为未完成。

## 推送

提交后立刻推当前分支：

```
git push -u origin HEAD
```

已跟踪远程则 `git push`。被拒时停下来报告，不要 `--force`。

**完成条件**：`git status -sb` 显示与 `origin/<branch>` 同步；本次 commit 已在远程。
