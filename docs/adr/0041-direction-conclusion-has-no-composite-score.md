# 方向结论不生成综合分

求职者校对当前角色、工作年限、技能点和明确熟练级后,系统只在可诊断岗位中逐层比较匹配档位、必备技能覆盖、有简历证据的岗位专属技能数、可迁移工程能力数,最后以数据新鲜度和证据充分度破同序,推荐三个岗位并显示每岗前两条理由；用户可改选两个比较。系统分别计算必备技能覆盖、简历证据充分度、可迁移工程能力、岗位专属经历和经验学历风险,模型只把这些可核对事实解释成方向结论。两个岗位处于同一档位且岗位专属证据与换档条件没有决定性差异时,结论明确写证据不足以区分,不强选胜者。简历定位、内容状态和岗位关键词对照同样只展示可核对的分项结论,不生成职业适配分、简历完整度分或 ATS 分数。
