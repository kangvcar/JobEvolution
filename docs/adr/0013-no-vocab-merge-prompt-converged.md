# 词表同义合并证据不足，暂不做；抽取提示词迭代按止损收敛

其中「词表保持现状,暂不做合并」的决定已由 ADR-0048 取代；本篇关于禁止余弦自动合并、评测独立性和提示词止损的其余决定继续有效。

JD F1 迭代（ADR-0012 框架下）的两条路线的实测结论与决定。

## 词表合并：证据不足，不做

- 0.85 余弦全量自动合并被证伪：词表塌出 74 条目的巨型簇（深度学习框架/机器学习/
  遗传算法/多模态融合/数学优化……），语义相邻≠同一技能，自动合并会毁掉图谱本体。
- 靶向合并同样无证据：255 个近义候选对里，跨名替换证据（预测 a / 金标 b）仅 4 次、
  全是孤例。近义词不是召回缺口来源；「沟通能力」有的行在金标、有的行不在，是逐行
  裁决方差，不是词表问题。
- 结论：词表保持现状。将来若做合并，必须人工逐对裁决（候选只来自实测致损组），
  且金标 id 重映射留痕，禁止按嵌入余弦自动合并。

## 提示词迭代：止损触发，收敛在 ~0.75

以人工裁决冻结的金标为参照、金标一字不动的六轮未 mock 迭代轨迹：

| 轮 | 动作 | JD F1 |
|---|---|---|
| 真基线 | 评测索引补嵌入（对齐恢复冻结阈值余弦口径） | 0.690 |
| 迭代 3 | 定义面 + 中文提示词 + 切片喂入 + 三点边界澄清 | 0.737 |
| 迭代 5 | 并列拆分（代码级 split_composite）+ 字段负担缓解 | 0.738 |
| 迭代 6 | 合成示例 few-shot | 0.751 |

止损约定（Q13）：两轮摸不到 0.80 即转如实汇报——已触发，收敛在 0.746–0.751。

剩余缺口的结构：抽取器与金标起草是两次独立 LLM 判读，「编程/算法/计算机」类
基础词粒度分歧（约百余条）与逐行方差是主体。继续抬升的手段里，改金标、词表
合并、阈值再校准均已被证据排除；剩下的选项是把抽取列表行为向起草行为收敛
（削弱提示词独立性，须另行 ADR 记取舍）或接受现值。

## 附带决定

- `split_composite`：并列串只在每部分都能精确命中词表时才拆（对齐侧共享实现，
  评测与管线同函数）。
- 阈值 0.70 经人工批准 mention 对重校准确认为最优，冻结不动。

## 终裁（2026-09-01）

不向起草行为收敛。JD F1 0.749（简历 0.993、匹配 1.000）为可交付的诚实答卷，
低于赛题 0.90 线的部分如实报告。理由：指标证明力优先于数字；收敛会削弱评测
独立性（预测与金标起草共享判读直觉），0.90 将成为带脚注的数字。若将来需要
重新评估此决定，走温和档（两段式 + 行为逼近）并另立 ADR 记取舍，不走提示词
复用。
