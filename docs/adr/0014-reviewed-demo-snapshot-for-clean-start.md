# 干净启动加载经审核的演示快照

发布包携带由正式管线产出、保留证据链并经过人工审核的版本化演示快照,干净环境幂等导入后即可走通产品主路径。演示快照不是第二套手录图,也不替代正式管线;变更演示数据必须重跑管线并重新审核。拒绝启动时现场调用 LLM 重建,因为结果会漂移、耗时且依赖外部服务;也不分发 Neo4j volume,因为它不可审阅且容易夹带本机状态。

快照包含全部获批公开图谱、预览层和两条来自正式管线的待审真事件,不含简历、管理员口令、金标工作状态或已撤回事实。快照同时记录 schema 版本、生成提交和证据文件哈希。

快照使用可审阅的版本化 JSON,按领域对象导出岗位定义版本、定义声明、要求版本、证据摘要、审核提案和审核决定。导入器先校验 schema 与文件哈希,再幂等写图;不提交 Neo4j dump、大段 Cypher 或自定义二进制。
