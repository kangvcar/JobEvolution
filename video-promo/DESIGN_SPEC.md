## 阶段 0：产品理解与执行约束

### 产品简报

**产品名称**：JobEvolution（智演）

**产品定位**：  
多源招聘数据驱动的岗位能力图谱产品。从招聘数据流中发现新兴岗位、追踪岗位要求演化、为求职者提供简历对照与职业迁移诊断。

**目标用户**：  
1. **主要用户**：1–5 年后端/全栈经验、准备转向大模型应用或 Agent 工程师岗位的求职者
2. **次要用户**：其他技术岗位求职者、企业 HR（管理后台）

**核心价值主张**：  
- **实时岗位发现**：从多源 JD 中识别新兴岗位（如 Agent 工程师）
- **能力演化追踪**：记录岗位要求边的变化（新增/升值/失效）
- **证据驱动诊断**：简历技能与岗位要求可对账，每条判断能回溯证据
- **换档路径推演**：换档模拟器、邻近岗位迁移地图、双轨行动清单

**必须展示的核心功能**（按优先级排序）：
1. 多源数据采集 → 岗位发现（萌芽/成型状态机）
2. 岗位能力图谱（技能点网络、切片差分标注）
3. 简历上传 → 智能诊断流程（匹配档位、缺口分析）
4. 换档模拟器（交互式试算）
5. 简历证据地图（经历与要求连线）
6. 邻近岗位迁移（共享能力 vs 独有要求）
7. 市场信号雷达（覆盖率、周期变化）
8. 管理后台待审流程

**技术架构**：
- 前端：Next.js + React + Recharts（图谱可视化）
- 后端：FastAPI + Neo4j（图谱数据库）
- 管线：每日采集 + 抽取 + 审核闸门
