### 场景 2：修改文案或颜色
```bash
cd promo-video
npm run start                    # 启动预览
# 编辑 src/PromoVideo.tsx
# 浏览器实时刷新，看到效果后：
npm run build                    # 重新渲染
```

### 场景 3：替换为真实数据截图
```bash
# 1. 将新截图放入 public/textures/
# 2. 编辑 src/PromoVideo.tsx，在对应镜头组件中：
<Img src={staticFile('textures/你的截图.png')} />
# 3. 重新渲染
```

### 场景 4：添加 BGM
```bash
# 1. 将音乐文件放入 public/audio/bgm.mp3
# 2. 在 src/PromoVideo.tsx 顶部添加：
<Audio src={staticFile('audio/bgm.mp3')} volume={0.3} />
# 3. 重新渲染
```
